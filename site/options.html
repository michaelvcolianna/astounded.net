Your options

Note: While it's a common practice around the web to open links to external websites in new tabs/windows, none of the links below does that because it can be detrimental to accessibility.

WordPress.com
WordPress-hosted site. One thing to note: If you want any plugins, you have to use one of the paid plans.
Self-hosted WordPress
WordPress on hosting you rent. It's the same product as above, but you have more features (and more upkeep).
Squarespace
Same concept as WordPress, but in a different package. They have premade themes you can customize.
Wix
Similar to Squarespace, with a different set of premade theme.
Ghost
Ghost has website features, but is geared more toward someone focused on audience-building – it has very powerful newsletter features. Like WordPress, they can host it for you at a cost, or you can self-host it.
Beehiiv
This one I don't have a lot of experience with. But it seems similar in scope to Ghost (newsletters), if a little less powerful (website).
A static site
This is either a bunch of HTML pages OR a "headless" CMS and a static site generator that creates a bunch of HTML pages. It is the fastest and most secure option, but either requires some tech savvy or help from a developer. Some generators & headless CMSes:
  • Generator: Next.js
  • Generator: Svelte
  • CMS: Contentful
  • CMS: Storyblok
Social media and link-in-bio pages
This covers stuff like Facebook pages or the collection of links like on Linktree or Carrd. They're free/cheap and quick to get using. They're also not super configurable.
