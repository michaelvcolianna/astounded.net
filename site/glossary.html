Glossary

Plain definitions of the technical words used on this site.

CMS (content management system)
The part of a website where you write and edit pages, without touching code.
DNS (domain name system)
The internet’s address book. It tells browsers which server your domain name points to.
Domain name
Your site’s address, such as astounded.net. You rent it yearly from a registrar.
Export
Downloading your content in a file so you can move it somewhere else.
Headless CMS
A CMS that only stores your writing. A separate tool decides how the website looks.
Hosting
Renting space on a computer that is always online, so people can visit your site.
Link-in-bio page
A single web page that lists your links, often used from a social media profile.
Lock-in
When leaving a platform is so hard that you’re stuck with it.
Markdown
A simple way of writing formatted text with ordinary characters, like *italic*.
Open source
Software whose code is public and free to use, change and host yourself.
Plugin
An add-on that gives a platform (usually WordPress) a new feature.
Registrar
A company you rent a domain name from.
Static site
A website made of ready-made pages. Nothing is built when someone visits, so it loads fast.
Static site generator (SSG)
A tool that turns your writing and a design into the pages of a static site.
Theme
A ready-made design for your site.
Transaction fee
A share of each sale that a platform keeps.
VPS (virtual private server)
Your own rented server. You control everything, and you look after everything.
